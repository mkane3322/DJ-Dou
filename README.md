Techonologies: JavaScript, CSS, React, RESTful APIs, MongoDB

Welcome to DJ Dou, this is a full-stack sonic fingerprinting web app!

DJ Dou connects to Spotify's public API to gain access to user accounts, and Spotify's
large music catalog. Each song has specific inherent tags to catergorize by Spotify itself
and that is what is used to track preferences and recommendations. 

13 of these tags covering a breadth of user preferences are tracked and displayed once the user
logs in to their dashboard. From this dashboard songs will be recommended in a list provided and
can be added, removed, or liked.

This web app allows for more accurate song recommendations for spotify users based on these sonic
fingerprints twisting the comcept of the regular spotify clone.

To use this web app in your IDE:

In Terminal 1 run:

cd dj-dou
cd backend
npm start dev

In Terminal 2 run:

cd dj-dou
cd frontend
npm start

From there the web app will open automatically in your default browser on a localhost.
